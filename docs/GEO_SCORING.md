# GEO 评分规则说明

## 版本体系

GEOkit 使用**双版本号**：

- **geoVersion**：模型代际（"1.0.0" | "2.0.0"），用户可选
- **scoringVersion**：评分规则细粒度版本（如 "2.1.0"），随规则更新递增

每次观测记录携带 `scoringVersion`，diff 引擎识别版本不同时保持可比并附加 caveat。

### scoringVersion 2.1.0 新信号（T9）

在六维 max 与总分 100 不变前提下，并入 5 个新页面级可观测信号：

| 维度 | 新信号 | 检测规则 | 权重影响 |
|------|--------|----------|----------|
| 可引用性 | 1.6 FAQ/Q&A 结构 | FAQPage JSON-LD 或 ≥2 个疑问句 heading + 答案块 | +3 |
| 结构化 | 2.5 结构化元素密度 | (listItems + tables*3) / max(paragraphs,1) | +2 |
| 实体清晰度 | 3.5 作者权威链接 | author.sameAs 或 article:author + 作者主页链接 | +2 |
| 事实密度 | 5.4 权威来源 | 外链含 .gov/.edu/.mil | +2 |
| 可读性/时效 | 6.3 更新时间一致性 | modified >= published 且距今 ≤365 天 | +2 |

### 子权重重分配

新增信号从既有子项让权，不新增并行总分：

- 可引用性：1.1(8→7) / 1.2(6→5) / 1.3(5→4)
- 结构化：2.1(6→5) / 2.4(4→3)
- 实体清晰度：3.2(4→3) / 3.3(3→2)
- 事实密度：5.2(5→4) / 5.3(4→3)
- 可读性：6.1(5→4) / 6.2(5→4)

## GEO 1.0.0（经典基线）

完全保持与项目既有 baseline 一致的特征统计打分体系，供历史比对与 CI 回归基线。
`scoringVersion = "1.0.0"`，冻结不动。

## 评分输出

每个维度输出：
- `score`：维度得分（0-max）
- `max`：维度满分
- `comment`：得分依据说明
- `breakdown`：子项得分明细

总分 = Σ(各维度得分) / Σ(各维度 max) * 100

## 版本升级策略

1. **不修改已发布的 scoringVersion**：旧版本规则冻结
2. **新版本递增**：规则更新时递增 scoringVersion（如 2.1.0 → 2.2.0）
3. **diff 兼容**：scoringVersion 不同时保持 comparable，但附加 caveat
4. **历史推断**：历史观测缺 scoringVersion 时按 geoVersion 推断初版规则
